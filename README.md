# Edge142

Edge142 is a personal local AI companion project.

The goal is to build an AI system that can understand voice and text commands and run on my device without sharing data with external servers. It is designed to eventually run efficiently even on low-end devices.

This project is also my practical learning laboratory for programming, Linux, software engineering, artificial intelligence, and machine learning.

## Development Device

- OS: Linux Mint 22.3 XFCE 64-bit

## Project Philosophy

Build Edge142 while simultaneously developing strong programming fundamentals and practical engineering skills.

Understand the system instead of blindly copying code.

## Current Capabilities

- Continuous text-based interaction
- Input normalization using lowercase conversion and whitespace removal
- Basic intent detection
- Greeting detection & Farewell detection
- Unknown-intent handling

## Current Architecture

User Input  
↓  
Input Normalization  
↓  
Intent Detection  
↓  
Response Generation
